Timing is *how long* a motion takes. Spacing is *where the object is* on each frame in between. Two motions with the same timing can feel completely different, and spacing is the whole difference.

Animators plan spacing with a chart: a line with a tick for every drawing. Close ticks mean the object barely moves between frames, so it looks slow. Wide ticks mean it jumps, so it looks fast. An easing curve is nothing more than a spacing plan written as maths.

<Beat kind="see">Same timing, four spacings</Beat>

Each row takes the same time over the same distance. Hover the figure to see every frame at once. Only the spacing differs.

- **Linear:** even gaps. It moves like a machine, because only machines keep a constant speed.
- **Ease-in:** tight gaps, then wide. It starts slowly and leaves fast.
- **Ease-out:** wide gaps, then tight. It moves fast and then settles.
- **Ease-in-out:** tight, wide, tight. It starts gently, travels, and lands gently.

<Beat kind="more">Enter with ease-out, exit with ease-in</Beat>

<Margin kind="history">
  <p>Robert Penner's easing equations, written for Flash around 2001, named the families still used today: quad, cubic, quart, expo, back, elastic, bounce.</p>
</Margin>

The rule follows from the world. **Things arrive and settle; things leave and accelerate.** An entrance should decelerate into place (ease-out). An exit should accelerate away (ease-in), and it should be quicker, because the thing that's leaving no longer needs your attention. On-screen moves, where something starts and ends in view, get both (ease-in-out).

This app's own curves follow it: `--ease-out` is `cubic-bezier(.2, .8, .2, 1)` for enters, `--ease-in` is `cubic-bezier(.4, 0, 1, 1)` for exits at 0.7× the time, and `--ease-inout` for moves.

<Beat kind="more">Reading a cubic-bezier</Beat>

`cubic-bezier(x1, y1, x2, y2)` draws a curve from the bottom-left corner (start) to the top-right (end). Time runs across, progress runs up. The four numbers are two **handles**:

- The first handle `(x1, y1)` sets the direction the curve *leaves* the start. Its slope is the starting speed.
- The second handle `(x2, y2)` sets the direction it *arrives* at the end. Its slope is the arriving speed.

A steep slope is fast. A flat slope is slow. So in `cubic-bezier(.2, .8, .2, 1)` the first handle points steeply up (it leaves fast) and the second lies flat along the top (it arrives slowly). A `y` above 1 means the curve overshoots its target and comes back.

<Figure n="3.2" caption="--ease-out, position and velocity">
  <CurvePlot easing="--ease-out" compare="linear" duration={600} label="--ease-out" compareLabel="linear" />
</Figure>

<Margin kind="def">
  <p><b>Velocity graph.</b> The slope of the position curve at every moment. 1× is the speed of linear motion over the same time. The tallest point is where the object is fastest.</p>
</Margin>

Read the velocity graph on the right: `--ease-out` starts at four times the speed of linear motion (0.8 ÷ 0.2, the slope of its first handle) and spends the second half of its time barely moving. That long, slow tail is the "settle". The spacing chart shows the same thing: the ghosts crowd together at the end.

Two more CSS spacings are worth knowing. `steps(n)` holds still and then jumps, so every gap is either zero or large: good for clocks, counters, and sprite sheets. `linear()` takes any list of stops, so it can draw spacing that no bézier can, like a bounce or a spring.

<Beat kind="tune">Drag the handles</Beat>

Start from `ease-out`. Its first handle sits in the corner; its second lies flat along the top, and that flat handle is the settle. Pull the second handle straight down onto the dotted diagonal. Watch the velocity peak shrink to 1× and the ghosts spread evenly. You're turning an arrival back into a machine. B is `ease-in`: the same curve turned around, the spacing of an exit.

<div class="snippets">
<Snippet title="03 · Spacing: arrive and settle" lab="curve-bench" easing="cubic-bezier(.2,.8,.2,1)" duration={280} from={16} to={0} property="y">

```css
/* Enter: decelerate into place. Exit: accelerate away, faster. */
.card-enter {
  transition: transform 280ms cubic-bezier(.2, .8, .2, 1),
              opacity   180ms linear;
}

.card-exit {
  transition: transform 196ms cubic-bezier(.4, 0, 1, 1),
              opacity   126ms linear;
}
```

</Snippet>

<Snippet title="03 · Spacing: steps and linear()" lab="spacing-chart" easing="steps(8)" duration={800} property="rotate" to={360}>

```css
/* Hold, then jump: eight positions per turn. */
.spinner { animation: spin 800ms steps(8) infinite; }
@keyframes spin { to { rotate: 1turn; } }

/* Any spacing you can draw, as stops: a small bounce. */
.drop {
  transition: transform 600ms
    linear(0, 0.36 20%, 1 40%, 0.81 55%, 1 70%, 0.95 85%, 1);
}
```

</Snippet>
